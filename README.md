Personal Portfolio Website – HTML & CSS

A personal portfolio website developed using HTML5 and CSS3 to present my professional profile, skills, projects, and contact details in a well-structured and visually appealing manner. The main objective of this project is to create a digital identity and showcase my abilities to recruiters and visitors through a simple and effective design.

The website consists of key sections such as Home, About Me, Skills, Projects, and Contact, allowing smooth navigation and clear content flow. HTML is used to structure the content semantically, while CSS is applied for layout design, color styling, typography, hover effects, and responsiveness.

The portfolio follows a clean and responsive design, ensuring compatibility across different devices and screen sizes. External CSS files and proper folder organization are used to maintain readability, reusability, and scalability of the code.

This project helped enhance my understanding of web design fundamentals, responsive layouts, and UI styling, and serves as a strong foundation for adding advanced features in the future. It demonstrates my ability to build a professional static website using core front-end technologies.
